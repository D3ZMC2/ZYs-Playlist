NEON//MEMORY — Browser Version

1. Open this folder in VS Code.
2. Install the Live Server extension if you want one-click running.
3. Right-click index.html -> Open with Live Server.

No Java and no FFplay are required.

Files:
index.html
style.css
script.js
music/song.mp3
images/cover.jfif

The supplied image is used as the artwork.
The lyrics panel has a real independent scrollbar. While music is playing, it follows the active lyric. Manually scrolling pauses follow mode; press SYNC to return to the current lyric.
